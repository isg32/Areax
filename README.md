## Building this App Yourself 

> Not Recommended, it is suggested to check for Deployments.

Clone this repo

```bash
git clone https://github.com/isg32/Areax.git
```

Install Dependencies

```bash
flutter pub get
```

Build!

```bash
flutter build apk --verbose --release
```
